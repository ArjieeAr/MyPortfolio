## Built with

- [Astro](https://astro.build): static site framework
- [Tailwind CSS](https://tailwindcss.com): styling
- TypeScript
- Deployed on [Vercel](https://vercel.com)

## Highlights

- Single-page layout: Hero, About, Skills, Projects, Blog and Contact
- Blog posts written in Markdown
- Dark mode by default, with a light mode toggle that remembers your choice
- Mobile-first, responsive design
- Accessible: keyboard navigation, visible focus styles, skip-to-content link
- Content lives in JSON and Markdown, so updating it doesn't mean touching the components

## Running locally

Requires Node.js 22.12+.

```bash
npm install
npm run dev
```
